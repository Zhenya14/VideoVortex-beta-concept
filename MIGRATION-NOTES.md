# VideoVortex Beta — порт функцій

## Цей етап
- Додано адаптований модуль сезонних тем із legacy-версії: Геловін (30–31 жовтня), Новий рік (15 грудня – 25 січня), День закоханих (13–14 лютого), День незалежності (23–24 серпня), День вишиванки (20–21 травня), великодній період (10–25 квітня).
- Ефекти винесені в `js/features/seasonal.js` та `css/seasonal.css`, використовують класи з префіксом `vv-season-`, не втручаються в старі DOM ID.
- Для снігу враховано `prefers-reduced-motion`; додано очищення попередніх ефектів.
- Збережено модульну SPA-архітектуру та Firebase Realtime Database.

## Що ще не перенесено
Це перший функціональний блок, а не повний порт усіх можливостей legacy. Далі потрібна адаптація функцій керування каналами, додаткових налаштувань профілю, архівів, підтримки/сповіщень, розширених сценаріїв завантаження, історій та сезонних банерів до нового API і розмітки.
